# The rule
#   A Tranco domain d is taken if its homepage is a website, a run can measure
#   it, it is not an adult site and its page is not already on the list. The
#   first 1000 such domains in Tranco order are the list.
#   1. Website means CrUX has one of https://www.d, https://d, http://www.d or
#      http://d, tried in that order. The first one it has is the origin that
#      is checked.
#   2. Measurable means bot-wall-check/check.py gave that origin the verdict
#      ok. Its final URL after redirects is what is listed, so the measured
#      load starts without a redirect. A query made only of tracking
#      parameters is removed, and so is a fragment. A site that redirects to a
#      consent gate on another host, with a session in the URL, is listed by
#      its origin instead.
#   3. Adult was decided by four signals. These are the family resolver
#      against the malware resolver, UT1, OISD and the RTA label. No signal
#      means not adult and all four mean porn. Every site they disagreed on
#      was decided by its title and domain, with the reason in
#      tools/adult-overrides.csv. Porn and other adult sites (escort and
#      sex-work ads, hookup and swinger sites, erotic stories, fetish
#      communities) are both left out.
#   4. Endpoints with no content of their own, such as connectivity checks,
#      are left out, as listed in tools/endpoint-overrides.csv.
#   5. Two domains whose final URL has the same host count once, at the better
#      Tranco rank.
#
# The bot-wall check ran on 2026-11-25 and left from 87.159.187.204 (AS3320
# Deutsche Telekom AG, DE). Bot managers treat addresses differently, so check
# again from the benchmark machine before a sweep.
#   bot-wall-check/results/tranco-JZW4Y-crux-202610-1-2000-20261125-144433.csv
